# Week 5 Task 2 - Image Resizing for YOLO Training

## Objective

Resize dataset images to smaller dimensions while preserving aspect ratio for efficient YOLO model training.

## Method

* Used Python and OpenCV for image resizing.
* Resized images to a width of 384 pixels.
* Preserved the original aspect ratio.
* Generated resized training and validation image datasets.

## Input Folders

* dataset/images/train
* dataset/images/val

## Output Folders

* dataset/images/train_resized
* dataset/images/val_resized

## Tools Used

* Python
* OpenCV

## Result

Successfully resized all training and validation images while maintaining aspect ratio, making them ready for YOLO model training.
