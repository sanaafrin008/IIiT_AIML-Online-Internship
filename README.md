# IIIT AIML Online Internship

## Project Title

Intelligent Visual Monitoring and Automated Object Analysis System

## Overview

This repository contains all tasks completed during the IIIT AIML Online Internship. The internship focused on developing practical skills in Computer Vision, Image Processing, Video Processing, Dataset Preparation, Semantic Segmentation, Object Detection, Transfer Learning, Model Training, and Deployment.

The work progressed from basic video frame extraction to building a complete computer vision pipeline capable of training a custom model, detecting objects, generating prediction outputs, and creating visual demonstrations.

---

## Internship Workflow

### Week 1 – Video Processing and Media Generation

* Downloaded video samples.
* Extracted image frames using FFmpeg.
* Reconstructed videos from image sequences.
* Added audio tracks and generated final video outputs.

### Week 2 – Virtual Environment and Pretrained Object Detection

* Created Python virtual environments.
* Installed required computer vision libraries.
* Executed pretrained object detection models.
* Generated annotated outputs on images and videos.

### Week 3 – Semantic Segmentation and Computer Vision Analysis

* Performed semantic segmentation.
* Generated segmentation outputs.
* Created comparison videos using original, detection, and segmentation outputs.
* Analyzed model performance metrics.
* Explored loss curves and evaluation results.

### Week 4 – Dataset Preparation and Custom Model Training

* Created training and validation datasets.
* Generated YOLO-compatible label files.
* Prepared metadata and configuration files.
* Trained a custom object detection model using transfer learning.
* Generated optimized model weights.

### Week 5 – Inference and Application Development

* Performed object detection using trained model weights.
* Generated prediction outputs on validation and test images.
* Created demonstration videos.
* Integrated visual outputs into a complete computer vision application workflow.
