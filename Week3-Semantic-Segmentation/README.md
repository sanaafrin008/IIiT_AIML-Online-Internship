# Week 3 Semantic Segmentation

## Objective
Perform semantic segmentation on video frames using YOLOv8 Segmentation.

## Video Source
https://www.youtube.com/shorts/hPsH7GJEQjg

## Tools Used
- Python
- Google Colab
- OpenCV
- YOLOv8 Segmentation
- MoviePy

## Workflow
1. Download YouTube Short
2. Extract Frames
3. Perform Segmentation
4. Save Segmented Images
5. Generate Segmented Video
6. Add Background Music
7. Collect Metrics

## Results
Successfully segmented objects from the road scene and generated a segmented video.

## Applications
- Autonomous Driving
- Medical Imaging
- Surveillance
- Robotics
